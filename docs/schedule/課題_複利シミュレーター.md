## この回でやること

毎月の積立が複利でどう増えるかを計算するUIをReactで作る。react-hook-form + zod・Vitest・Storybookの復習を兼ねた、これまでの回の総合演習。

題材は[番外編: お金の授業](番外編_お金の授業.md)の「5. 複利」。先にそちらを読んでいると、何を作っているかが分かりやすい。

## 仕様

- 入力: 毎月の積立額 / 年利(%) / 年数
- 出力: 元本 / 最終額 / 増えた分
- できれば年ごとの推移をグラフかテーブルで表示する

### 計算ロジック

```ts
// 毎月積立の将来価値（期末払い）
export function futureValue(monthly: number, annualRatePercent: number, years: number): number {
  const r = annualRatePercent / 100 / 12
  const n = years * 12
  if (r === 0) return monthly * n
  return monthly * ((Math.pow(1 + r, n) - 1) / r)
}
```

## 手順

1. `futureValue` を純粋関数として切り出し、Vitestでテストを書く（利率0%のケース・既知の値。例: 月3万円・年利5%・30年 ≒ 2,500万円）
2. 入力フォームを react-hook-form + zod で作る（負数・空欄・上限のバリデーション）
3. 結果を表示する。元本と増えた分が一目で分かるように
4. 年ごとの推移をテーブルで出す。余裕があればグラフ
5. Storybook にフォームと結果表示を登録する

## やってみると効く実験

- 年利を5%と7%で比べる
- 開始を10年遅らせる
- 積立額を1.5倍にする

**「開始を10年遅らせる」損失の大きさ**を自分の目で見る。複利の効果を最大化する変数は利率ではなく時間だと分かる。
