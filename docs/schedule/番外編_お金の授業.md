## 1. 税金 — 給料から何が引かれているのか

### 給与明細の3層構造

| 区分               | 中身                                         | ポイント                            |
| ------------------ | -------------------------------------------- | ----------------------------------- |
| 総支給（額面）     | 基本給＋残業代＋手当                         | 求人票の「月給」はここ              |
| 控除               | 所得税・住民税・健康保険・厚生年金・雇用保険 | ざっくり**額面の2割前後**が引かれる |
| 差引支給（手取り） | 実際に振り込まれる額                         | 額面25万円なら手取り20万円前後      |

**まずこれを体感する**: 「年収400万円」は手取り400万円ではない。額面と手取りの差を知らないまま生活設計すると必ず詰まる。

### 税金のしくみ（最小限）

- **所得税**: 国に払う。累進課税（稼ぐほど税率が上がる、5%〜45%）。給料から毎月「だいたいの額」が天引き（源泉徴収）され、年末に正しい額へ調整（年末調整）される
- **住民税**: 自治体に払う。**前年の所得**に対して、ほぼ一律10%。1年遅れでやってくるのが要注意（新卒2年目に手取りが減ったように感じるのはこれ）
- **社会保険料**: 健康保険・厚生年金。税金ではないが、実は所得税より高いことが多い。会社が同額を負担している

### 所得控除 = 税金が安くなる仕組み

税金は「収入 × 税率」ではなく「**(収入 − 経費 − 控除) × 税率**」で決まる。控除を知っているかどうかで払う額が変わる。

代表的なもの: 基礎控除／給与所得控除／扶養控除／社会保険料控除／生命保険料控除／医療費控除／寄附金控除（＝ふるさと納税）／iDeCoの小規模企業共済等掛金控除

### 学生・アルバイトが関係する「年収の壁」

学生バイトでよく聞く「103万円の壁」は、**2025年分から引き上げられた**（給与所得控除と基礎控除の見直し）。また19〜22歳の扶養についても、以前は「103万円を1円でも超えると親の控除がゼロ」だったのが、**段階的に減る仕組み**に変わっている。

> 金額は改正で動くので、**「いくらまで」は毎年、国税庁のサイトで確認する**こと。ここで覚えるべきは金額そのものではなく次の2点。
>
> - 壁には**税金の壁**（所得税・住民税・親の扶養）と**社会保険の壁**（自分で健保・年金を払う）の2種類がある
> - 効くのは社会保険の壁のほう。税金の壁は少し超えても手取りが逆転することはほぼない

## 2. 確定申告 — 自分で税金を計算して申告する

### 年末調整と確定申告の違い

- **年末調整**: 会社が代わりにやってくれる精算。会社員はこれで終わることが多い
- **確定申告**: 自分でやる精算。毎年**2月16日〜3月15日**ごろ（対象は前年1〜12月）

### 確定申告が「必要」な人（デザイナー・エンジニアに多いケース）

- フリーランス・業務委託で働いている
- 会社員だが**副業の所得が年20万円を超える**（案件・広告収入・物販など）
- 給与を2か所以上からもらっている
- 6か所以上の自治体にふるさと納税した／医療費控除など他の申告もする

> 補足: 副業所得20万円以下なら所得税の確定申告は不要だが、**住民税の申告は必要**。「20万円以下なら何もしなくていい」は誤り。

### 確定申告すると「得する」人

- 医療費が年10万円を超えた（医療費控除）
- 年の途中で退職して年末調整を受けていない
- 住宅ローンを組んだ1年目
- ふるさと納税をしてワンストップ特例を使わなかった

### やり方

1. **e-Tax**（国税庁の確定申告書等作成コーナー）をブラウザで開く
2. マイナンバーカード＋スマホで認証
3. 源泉徴収票・支払調書・控除証明書の数字を入力
4. 送信 → 還付があれば1か月ほどで口座に振り込まれる

**フリーランスになるなら**: 開業届＋青色申告承認申請書を出すと青色申告特別控除（最大65万円）が使える。会計freeeやマネーフォワードなどのクラウド会計を使えば、簿記の知識がなくても入力できる。**日々のレシートと請求書を捨てないことがすべて**。

## 3. ふるさと納税 — 税金の前払いで返礼品をもらう

### しくみ

「納税」という名前だが実態は**自治体への寄附**。寄附額のうち2,000円を超える部分が、翌年の住民税・所得税から差し引かれる。

**つまり**: 実質2,000円の自己負担で返礼品（寄附額の3割相当まで）がもらえる。**節約ではなく「払う場所を変えるだけ」**という理解が正しい。

### 絶対に外せない注意点

- **上限額がある**。年収・家族構成で決まる控除上限を超えた分は、ただの寄附になる（戻ってこない）。各サイトのシミュレーターで必ず試算する
- **そもそも税金を払っていない人は損しかしない**。学生・無収入・住民税非課税の人がやると、2,000円払って返礼品を買っただけになる。**社会人になって、住民税を払うようになってから始める**
- **名義は本人**。自分が納税者でないといけない
- **ワンストップ特例**: 確定申告しない会社員で、寄附先が5自治体以内なら、申請書を出すだけで確定申告不要。**申請期限は翌年1月10日必着**。ただし確定申告をすると**ワンストップは無効になる**ので、その場合は寄附金控除も確定申告に含める
- 仲介サイトのポイント付与は規制された。**サイト選びのうまみは以前より小さい**

### 手順

1. シミュレーターで上限額を確認する
2. ポータルサイト（さとふる／楽天ふるさと納税／ふるなび等）で返礼品を選んで寄附する
3. ワンストップ特例の書類を返送する（または確定申告する）
4. 翌年6月の住民税決定通知書で、控除されているか確認する ← **ここまでやって完了**

## 4. 投資とNISA

### 前提: 投資の前にやること

1. **生活防衛資金**を貯める（生活費の3〜6か月分を現金で）
2. **高金利の借金を返す**（リボ・カードローンは年15%前後。どんな投資より確実に「年15%の損失」を止められる）
3. 余った金で投資する

順番を守らないと、暴落時に生活費が必要になって最悪のタイミングで売る羽目になる。

### 何に投資するのか

| 対象                     | 特徴                                                                           |
| ------------------------ | ------------------------------------------------------------------------------ |
| 個別株                   | 1社に賭ける。上下が激しい。企業分析が必要                                      |
| **インデックスファンド** | 何百〜何千社にまとめて投資する詰め合わせ。全世界株式（オルカン）やS&P500が定番 |
| 債券                     | リターンは低いが値動きが小さい                                                 |
| 不動産・FX・暗号資産     | レバレッジがかかると一気に飛ぶ。初手では扱わない                               |

初心者向けの一般的なセオリーは「**低コストのインデックスファンドを、毎月定額で、長期間積み立てる**」。理由は次のとおり。

- **分散**: 1社が潰れても全体は死なない
- **低コスト**: 信託報酬（保有中ずっと引かれる手数料）が年0.1%か年1.5%かで、30年後には数百万円の差になる。**手数料は唯一、確実にコントロールできる要素**
- **時間分散（ドルコスト平均法）**: 毎月同額を買うと、高いときは少なく・安いときは多く買える。買うタイミングを当てにいかなくて済む

### NISAとは

通常、投資で得た利益には**約20%（20.315%）の税金**がかかる。100万円儲けたら約20万円取られる。

**NISA = この税金がゼロになる口座**。2024年から新制度になった。

| 項目                   | 内容                                           |
| ---------------------- | ---------------------------------------------- |
| つみたて投資枠         | 年120万円まで。長期積立に適した投資信託に限定  |
| 成長投資枠             | 年240万円まで。個別株なども対象                |
| 年間合計               | **360万円**                                    |
| 生涯の非課税保有限度額 | **1,800万円**（うち成長投資枠は1,200万円まで） |
| 非課税期間             | **無期限**                                     |
| 売ったとき             | 翌年、その分の枠が復活して再利用できる         |

- 口座は**1人1口座**（金融機関は年単位で変更可）。手数料と取扱本数からネット証券が選ばれることが多い
- **iDeCo**との違い: iDeCoは掛金が全額所得控除になる代わりに、**原則60歳まで引き出せない**。流動性が必要な若いうちはNISA優先が一般的なセオリー

> ⚠️ NISAは「口座の種類」であって、儲かる商品ではない。**NISAでも元本割れはする**。

## 5. 複利 — この回でいちばん大事な概念

### 単利と複利

- **単利**: 元本にだけ利息がつく
- **複利**: 利息にも利息がつく。増えた分が次の利息を生むので、**時間が経つほど加速する**

### 72の法則

```
資産が2倍になる年数 ≒ 72 ÷ 年利(%)
```

- 年利6% → 約12年で2倍
- 年利3% → 約24年で2倍
- 年利0.001%（かつての普通預金）→ 約72,000年で2倍

**この式は逆向きにも使える**。「年利36%」を謳う話は「2年で倍」と言っているのと同じ。**その時点で怪しいと気づける**。

### 積立の威力（年利5%と仮定した場合の概算）

| 毎月の積立 | 期間 | 元本      | 最終額（概算） |
| ---------- | ---- | --------- | -------------- |
| 3万円      | 10年 | 360万円   | 約466万円      |
| 3万円      | 20年 | 720万円   | 約1,233万円    |
| 3万円      | 30年 | 1,080万円 | 約2,500万円    |

30年では、元本1,080万円に対して**増えた分が1,400万円超**。増えた分のほうが元本より大きくなる。**複利の効果を最大化する変数は利率ではなく「時間」**で、20代で始められることが最大の武器になる。

※ これは「毎年きっちり5%増える」場合の計算。実際の相場は上下しながら平均的にこうなるだけで、**保証ではない**。

## 6. 年利の相場を知る = 詐欺を避ける最強の武器

### 相場観

| 対象                                       | 年利の目安                                          |
| ------------------------------------------ | --------------------------------------------------- |
| 普通預金                                   | 0.0x〜0.数%                                         |
| 個人向け国債・定期預金                     | 0.数〜1%程度                                        |
| 全世界株式インデックス（長期平均）         | **年5〜7%程度**（ただし変動し、マイナスの年もある） |
| 一部のヘッジファンド（プロが全力でやって） | 年10%台が出れば優秀                                 |
| リボ払い・カードローン（払う側）           | **年15%前後**                                       |

**覚えるのはこの1行**: 世界中のプロが本気でやって**年5〜7%**。

だから「**元本保証で月利3%（＝年利36%超）**」という話が来たら、それはプロの数倍の成績を、リスクゼロで、なぜか無名のあなたに配ってくれる、という主張になる。**成立しない**。

### ポンジ・スキーム

1920年代のチャールズ・ポンジに由来する古典的詐欺。

**しくみ**: 運用などしていない。**新しい出資者から集めた金を、古い出資者への「配当」として払う**だけ。最初のうちは本当に配当が出るので、信じた人が家族や友人を連れてくる。新規が途絶えた瞬間に破綻する。**構造上、必ず破綻する**。

**危険信号（1つでも当てはまったら関わらない）**

- **元本保証**＋**高利回り**の同時主張（最重要。リスクとリターンは必ず比例する）
- 「月利◯%」「年利20%以上」を**確実に**と言う
- **紹介すると報酬**（MLM構造）。友人・先輩・SNSの知人から来る
- 運用の中身を説明できない／「AIが自動で」「海外の特別なルート」と抽象的
- **金融庁の登録がない**（金融商品取引業者の登録番号を名乗れない）
- 「今だけ」「あなただけ」「秘密にして」と急かす・口止めする
- 出金しようとすると手数料や条件をつけて渋る

**確認方法**: 金融庁サイトの「**免許・許可・登録等を受けている業者一覧**」と「**無登録で金融商品取引業を行う者の名称等について**」（警告リスト）で名前を検索する。30秒でできる。

> 若手社会人は**狙われる側**。「同級生から久しぶりに連絡が来て、カフェで先輩を紹介される」は典型パターン。断れないなら「親／詳しい人に相談してから」で持ち帰る。**まともな金融商品は、持ち帰って冷静に検討されても困らない**。

## 7. 保険 — 入るべきもの、たぶん要らないもの

### 大原則

保険は「**起きる確率は低いが、起きたら貯金では払えない損害**」に備えるもの。

- 貯金で払える金額 → **保険にしない**（手数料の分だけ損）
- 払えない金額（数千万〜億） → **保険にする**

**宝くじと同じで、期待値では必ず負ける**（保険会社の経費と利益が乗っているため）。それでも入るのは、破産を避けるため。

### まず知るべきは「公的保険」

民間保険を検討する前に、すでに加入している公的保険の手厚さを知る。

- **高額療養費制度**: 医療費の自己負担には月あたりの上限がある。平均的な年収なら**月10万円弱程度**で頭打ち（所得区分による）。「がんになったら1,000万円かかる」は、この制度を無視した営業トーク
- **傷病手当金**: 会社員が病気で働けない間、給与の約2/3が最長1年6か月出る
- **遺族年金・障害年金**: 死亡時・障害時に家族へ支給される
- **労災保険**: 業務中・通勤中のケガ

> 高額療養費の上限額は引き上げが議論されている領域なので、**最新の自己負担額は必ず公式で確認**する。

### 一般に「必要性が高い」とされる保険

| 保険                   | 理由                                                                                   |
| ---------------------- | -------------------------------------------------------------------------------------- |
| **火災保険**           | 家が全焼＝数千万円。賃貸でも借家人賠償責任は必須級                                     |
| **自動車保険（任意）** | 対人・対物は**無制限**で。人身事故の賠償は億単位になりうる。自賠責だけでは全く足りない |
| **掛け捨ての死亡保険** | **扶養する家族がいる場合のみ**。独身で誰も困らないなら不要                             |
| （自転車保険）         | 自治体によっては加入義務。高額賠償の判例がある                                         |

### 一般に「不要では」と言われがちな保険

| 保険                                                   | 理由                                                                                                                             |
| ------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------- |
| 医療保険・入院保険                                     | 高額療養費制度がある。入院日額5,000円のために月々払い続けるより貯金のほうが自由が利く                                            |
| がん保険                                               | 同上。ただし自由診療まで備えたい等の価値観なら選択肢                                                                             |
| **貯蓄型保険**（終身・学資・個人年金・外貨建て・変額） | **保障と貯蓄がセットで手数料が見えにくい**。途中解約すると元本割れする。「保険は掛け捨て、貯蓄は貯蓄」で分けるほうがコストが明瞭 |
| スマホ保険・延長保証など                               | 損害額が小さい＝貯金で払える範囲                                                                                                 |

**ポイントは「不要と断定すること」ではなく、判断基準を持つこと**: ①その損害は貯金で払えるか ②公的保険でどこまでカバーされるか ③手数料はいくらか。この3つを聞いて答えられない勧誘からは買わない。

## 8. 両学長 / リベラルアーツ大学

このジャンルの入り口として定番の情報源。**この回の内容の多くは、ここで体系的に無料で学べる**。

- YouTube: **両学長 リベラルアーツ大学**
- 書籍: **『本当の自由を手に入れる お金の大学』**（改訂版あり）
- サイト: リベラルアーツ大学（リベ大）

### 中心にある考え方「5つの力」

1. **貯める**（支出を減らす） — 固定費（通信費・保険・家賃・車・サブスク）から削る。効果が大きく、一度やれば続く
2. **稼ぐ**（収入を増やす） — 給与所得＋事業所得。**我々はここが強い**（Web制作・デザイン・コーディングは副業にしやすい）
3. **増やす**（投資する） — インデックス投資が基本
4. **守る**（減らさない） — 詐欺・ぼったくり商品・浪費を避ける
5. **使う**（満足度を上げる） — 貯めるのが目的ではない

### ピックアップして見ておくとよいテーマ

- **固定費の見直し**（格安SIM・不要な保険の解約） — いちばん即効性がある
- **保険は「確率は低いが損失が大きいもの」だけ** — 上の7章の元ネタ
- **インデックス投資と手数料の話**（ぼったくり投資信託の見分け方）
- **副業・小さな事業の始め方**（Web制作は頻出テーマ）
- **搾取される人の共通点／怪しい儲け話の見分け方**

> ⚠️ 情報源のリテラシーも同時に学ぶ: 両学長に限らず、**特定の1人の言うことを鵜呑みにしない**。書籍・金融庁の資料・他の発信者と照らし合わせる。「この人が言ったから」で数百万円を動かさない。逆に、**この回の内容も同じように検証してよい**。

## 演習

### 演習1: 手取りを計算する（20分）

### 演習2: ふるさと納税シミュレーター（15分）

想定年収（300万・500万・800万）で控除上限額を比較する。**年収が低いと上限も小さい**こと、学生の自分が今やると損なことを確認する。

### 演習3: 複利シミュレーターを実装する（60分）

**この授業の本題**。Reactで積立の将来価値を計算するUIを作る。

入力: 毎月の積立額 / 年利(%) / 年数
出力: 元本 / 最終額 / 増えた分（できれば年ごとの推移をグラフかテーブルで）

```ts
// 毎月積立の将来価値（期末払い）
export function futureValue(monthly: number, annualRatePercent: number, years: number): number {
  const r = annualRatePercent / 100 / 12
  const n = years * 12
  if (r === 0) return monthly * n
  return monthly * ((Math.pow(1 + r, n) - 1) / r)
}
```

- 入力のバリデーションは react-hook-form + zod（7.1の復習）
- `futureValue` のテストを Vitest で書く（利率0%のケース・既知の値）（3.3の復習）
- 余裕があれば Storybook にコンポーネントを登録する（3.4の復習）

**やってみると効く実験**: 年利を5%と7%で比べる／開始を10年遅らせる／積立額を1.5倍にする。**「開始を10年遅らせる」損失の大きさ**を自分の目で見る。

### 演習4: 詐欺判定クイズ（15分）

いくつかの勧誘文句を見て、危険信号を指摘する。

- 「元本保証・月利3%・友達を紹介するとボーナス」

- 「信託報酬0.1%の全世界株インデックス、元本保証なし」
