## この回でやること

ブログの画像を `next/image` に置き換えて、「画像が重い」「読み込みでレイアウトが跳ねる」を仕組みで解決する。フォント（next/font）と同じ「重いアセットをフレームワークに最適化させる」考え方の画像版。

## 手順

### 1. なぜ画像最適化かを知る

ページの転送量の大半は画像。WebP/AVIFへの自動変換・リサイズ・遅延読み込みをNext.jsがやってくれる。

### 2. `<img>` と `next/image` を見比べる

同じ画像を両方で表示して、DevToolsのNetworkタブでフォーマットと転送量の差を見る。

### 3. ブログの画像を `<Image>` に置き換える

`width` / `height` と `alt` を必ず指定する（width/heightがレイアウト跳ね防止になる）。

### 4. `priority` を知る

ファーストビューの画像（ヒーロー・最初のカード）にだけ付ける。

### 5. GitHubへpush

## 注意・ヒント

- microCMSの画像（サムネイル）を表示する回では、外部ドメインの許可（`next.config` の `images.remotePatterns`）が必要になる
- `alt` は内容を表す文を書く。装飾画像は `alt=""`

## 宿題

- 全ページの `<img>` を `next/image` に置き換えてpushしてくる
