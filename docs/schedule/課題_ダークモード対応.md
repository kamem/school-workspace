## この回でやること

「色をCSS変数（トークン）で一括管理する」というデザインシステムの根幹の考え方を知り、自分のブログにダークモードを実装する。切り替えスイッチ（太陽⇄月）のマイクロインタラクションも合わせて作る。

## 手順

### 1. なぜダークモードがあるかを知り、実例を観察する

- 好み・目の負担・有機ELの省電
- GitHub・YouTubeなどの実例をライト/ダークで見比べる
- 「色の直書き」がダークモード対応を不可能にする理由

### 2. 色をCSS変数に整理する

`:root` に `--bg` `--text` `--card` などを定義し、直書きの色を全部変数参照に置換する。

### 3. ダークテーマを定義する

`[data-theme="dark"]` で変数を上書きする。変数の値だけで全画面が切り替わる瞬間がハイライト。

### 4. OS設定に追従させる

`prefers-color-scheme` で初期値を決める。

### 5. トグルスイッチを作る

太陽⇄月がSVGで変形・回転するスイッチを作る（`useState` + `data-theme` 切替 + CSS transition）。太陽⇄月は回転＋opacity切替が定番。イージングで「カチッと感」を出す。

### 6. 選択を記憶する

localStorageに保存し、再訪時に復元する（初回描画のちらつき対策は深追いしなくてよい）。

### 7. Storybookに登録する

スイッチとライト/ダーク両テーマのストーリーを登録する。

## 注意

- **ダークモードは「色反転」ではなく「再設計」**: 純黒（#000）は避ける、影は暗さではなく明度差で表現、彩度の高い色はダーク背景で目に痛いので落とす——デザイン志望には特に重要
- CSS変数による色の一括管理＝単位6で見るデザインシステムの「トークン」そのもの。完成品UIライブラリ（MUI等）のテーマ機能はこれを仕組み化したもの
- `prefers-color-scheme` は `prefers-reduced-motion` と同じ「OS設定を尊重する」思想の仲間
