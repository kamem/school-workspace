## ねらい

自分のブログにダークモードを実装する。「色をCSS変数（トークン）で一括管理する」というデザインシステムの根幹の考え方と、切り替えスイッチ（太陽⇄月）のマイクロインタラクションを合わせて学ぶ。

## タイムテーブル

- 講義・観察 30分: なぜダークモードがあるか（好み・目の負担・有機 ELの省電）/ GitHub・YouTubeなどの実例をライト/ダークで見比べる / 「色の直書き」がダークモード対応を不可能にする理由
- 制作 120分:
  1. **色をCSS変数に整理**: `:root` に `--bg` `--text` `--card` などを定義し、直書きの色を全部変数参照に置換
  2. **ダークテーマ定義**: `[data-theme="dark"]` で変数を上書き（変数の値だけで全画面が切り替わる瞬間がハイライト）
  3. **OS設定に追従**: `prefers-color-scheme` で初期値を決める
  4. **トグルスイッチ制作**: 太陽⇄月がSVGで変形・回転するスイッチを作る（`useState` + `data-theme` 切替 + CSS transition）
  5. **記憶**: localStorageに保存し、再訪時に復元（初回描画のちらつき対策は紹介程度）
  6. Storybookにスイッチとライト/ダーク両テーマのストーリーを登録
- 見せ合い 30分: お互いのダークテーマの色選びを比較

## 教えるポイント

- **ダークモードは「色反転」ではなく「再設計」**: 純黒（#000）は避ける、影は暗さではなく明度差で表現、彩度の高い色はダーク背景で目に痛いので落とす——デザイン志望に一番教えたい部分
- CSS変数による色の一括管理＝単位6で見るデザインシステムの「トークン」そのもの。完成品UIライブラリ（MUI等）のテーマ機能はこれを仕組み化したもの、と接続して説明
- `prefers-color-scheme` は `prefers-reduced-motion` と同じ「OS設定を尊重する」思想の仲間
- スイッチの太陽⇄月は回転＋opacity切替が定番。イージングで「カチッと感」を出す
