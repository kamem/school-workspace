## ねらい

microCMS連携済みのブログをVercelで公開し、APIキーを環境変数で安全に扱う方法を学ぶ。

## タイムテーブル

- 講義・デモ 60分: 環境変数とは / `.env` と `.gitignore`（**APIキーをGitにコミットしない**）/ Vercelとは・GitHub連携での自動デプロイ
- ハンズオン 90分: `.env.local` にmicroCMSのAPIキーを移す → Vercelにプロジェクト連携 → 環境変数をVercel側に設定 → デプロイして公開URL取得
- 演習・質疑 30分: microCMSで記事を追加 → 公開サイトに反映されるまでの流れを確認、積み残しの回収と後期前半の総復習（HTML/CSS→コンポーネント→CMS連携の道のり）。年内最終回の締め

## 教えるポイント

- 「秘密の値はコードに書かない」は実務の鉄則。うっかりコミットした場合のリスク（キーの無効化・再発行）まで話す
- push → 自動デプロイの体験は「Gitを使う理由」の答え合わせにもなる
