## この回でやること

ビルドツールの役割を知り、Viteで開発環境を立ち上げて、前期に作ったHTML/CSSページを移行する。ここで作るプロジェクトが後期の開発すべての土台になる。

## 手順

### 1. ビルドツールを知る

- なぜビルドツールが必要か
- 開発サーバーとHMR

### 2. Viteプロジェクトを作成する

`npm create vite` でプロジェクトを作る。

### 3. 前期ページのコードを移行する

前期に作ったHTML/CSSページのコードを移行する（移行前と後で何が楽になったかを体感）。

### 4. ビルドして中身を見る

`npm run build` して dist の中身を見る。

### 5. GitHubへpush

## 注意

- 同日に行うlinter/formatter導入もこのプロジェクトに対して行う。以降の開発（JS/Reactなど）もこの環境の上で進めるスタイル

## 宿題

- 移行したプロジェクトで気になるところを1箇所改善してくる
