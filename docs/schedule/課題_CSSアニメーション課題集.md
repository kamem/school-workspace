## 課題① ローディング＆スケルトンスクリーン

記事一覧の読み込み中に表示するスケルトン（骨組みがシマシマ光るやつ）を作る。「待ち時間のデザイン」というUX観点を学ぶ。

- 講義: なぜ待ち時間のデザインが必要か（体感速度）/ スピナーとスケルトンの使い分け / YouTube・Xなどのスケルトン観察
- 制作: ArticleCardのスケルトン版コンポーネント → `@keyframes`＋グラデーションでシマーエフェクト → 読み込み状態で本物と切り替え → Storybookに登録
- ポイント: スケルトンは「本物と同じ形」が命。レイアウトがズレると逆効果（CLSの話の入口）。シマーの速度は1秒前後が定番
- 宿題: ブログの全ページにスケルトンを適用

## 課題② マイクロインタラクション（いいねボタン）

クリックするとハートが弾ける「いいねボタン」を1つ作り込む。小さな部品に3時間かけることで「操作への気持ちいいフィードバック」の価値を学ぶ。

- 講義: マイクロインタラクションとは / Xのいいね・Instagramのハートをコマ送りで観察
- 制作: SVGハート＋`useState`でON/OFF → scale＋バウンス系イージングで弾み → パーティクル（擬似要素 or canvas-confetti）→ カウント＋localStorage（余裕があれば）→ Storybookに登録して記事詳細ページに設置
- ポイント: イージング（`cubic-bezier`）で「気持ちよさ」が決まる——同じ動きでイージングだけ変えて比較するデモが効く。連打されても壊れない状態管理。emilkowalskiの `animation-vocabulary` スキル（1.5参照）でAIへの指示語彙を増やせる
- 宿題: いいね以外のマイクロインタラクションを1箇所追加（コピーボタンの✓化など）

## 課題③ テキストアニメーション

ヒーロー見出しを1文字ずつ動かす。`animation-delay` の連番という1つのテクニックで見栄えが激変することを体験する。

- 講義: テキストアニメの名作サイト観察 / 種明かし（文字をspanに分割して遅延を連番でかけるだけ）
- 制作: `<AnimatedText text="..." />` コンポーネント自作（split＋mapの復習になる）→ `animation-delay: calc(var(--index) * 0.05s)` で順番に発火 → フェード / 下からスライド / ブラー解除 / タイプライター風のパターンを試す → ブログのヒーロー見出しに適用
- ポイント: 「全部同時」と「順番に（スタガー）」の印象差を比較して見せる。日本語は1文字単位・英語は単語単位が自然。長文には使わない（読みにくさの元凶）
- 宿題: 好きなパターンをヒーロー見出しに適用してpush

## 共通の注意

- `prefers-reduced-motion` への配慮を全課題共通のチェック項目にする
- アニメーションは「目的（誘導・フィードバック・演出）があるか」で入れる場所を決める。動かすこと自体を目的化しない
