## この回でやること

就職すると、誰も教えてくれないまま「税金が引かれた給料」「保険の勧誘」「投資の話」がいきなり来る。この回は**社会に出る前に知っておくと数十万〜数百万円の差になる知識**を、判断基準だけに絞って扱う。

> **最初に断っておくこと**
>
> - 講師は税理士でもFPでもない。ここで話すのは「一般的な制度の説明」であって、個別の税務相談・投資助言ではない
> - **制度は毎年変わる**。数字は授業時点のもので、実際に手続きするときは必ず公式（国税庁・金融庁・自治体）で最新を確認する
> - 「この商品を買え」という話は一切しない。**判断の材料と、危ないものを避ける基準**を渡すのがこの回の目的

## 導入: これ、どれが詐欺？（10分）

まず4つの勧誘文句を見て、「乗る／乗らない」を直感で答えてもらう。答え合わせは2章の後。

1. 「元本保証・月利3%・友達を紹介するとボーナス」
2. 「AIが自動売買、年利30%、実績のスクショあり」
3. 「信託報酬0.1%の全世界株インデックス、元本保証なし」
4. 「毎月分配型で分配金利回り12%」

## 1. 手取りの衝撃 — 「年収400万円」は400万円もらえない

### 給与明細の3層構造

| 区分               | 中身                                         | ポイント                            |
| ------------------ | -------------------------------------------- | ----------------------------------- |
| 総支給（額面）     | 基本給＋残業代＋手当                         | 求人票の「月給」はここ              |
| 控除               | 所得税・住民税・健康保険・厚生年金・雇用保険 | ざっくり**額面の2割前後**が引かれる |
| 差引支給（手取り） | 実際に振り込まれる額                         | 額面25万円なら手取り20万円前後      |

額面と手取りの差を知らないまま生活設計すると必ず詰まる。**求人票の月給は「もらえる額」ではない**。

### 引かれているものは3つだけ覚える

- **所得税**: 国に払う。稼ぐほど税率が上がる。毎月「だいたいの額」が天引きされ、年末に会社が精算してくれる（年末調整）
- **住民税**: 自治体に払う。**前年の所得に対して**かかるので、**1年遅れでやってくる**。新卒2年目に手取りが減ったように感じるのはこれ
- **社会保険料**: 健康保険・厚生年金。税金ではないが、**実は所得税より高い**。会社が同額を負担している

### 学生バイトの「年収の壁」は2種類ある

金額は改正で毎年動くので覚えなくていい。覚えるのは次の2点だけ。

- 壁には**税金の壁**（自分の所得税・親の扶養）と**社会保険の壁**（自分で健保・年金を払う）の2種類がある
- **効くのは社会保険の壁のほう**。税金の壁は少し超えても手取りが逆転することはほぼない

> 改正メモ: 学生バイトの「103万円の壁」は**2025年分から引き上げられた**（給与所得控除と基礎控除の見直し）。19〜22歳の扶養についても、以前は「103万円を1円でも超えると親の控除がゼロ」だったのが、**段階的に減る仕組み**に変わっている。金額は毎年、国税庁のサイトで確認する。

## 2. 詐欺の見抜き方 — 年利の相場を知っていれば30秒で分かる

### 相場観

| 対象                                       | 年利の目安                                          |
| ------------------------------------------ | --------------------------------------------------- |
| 普通預金                                   | 0.0x〜0.数%                                         |
| 個人向け国債・定期預金                     | 0.数〜1%程度                                        |
| 全世界株式インデックス（長期平均）         | **年5〜7%程度**（ただし変動し、マイナスの年もある） |
| 一部のヘッジファンド（プロが全力でやって） | 年10%台が出れば優秀                                 |
| リボ払い・カードローン（払う側）           | **年15%前後**                                       |

**覚えるのはこの1行**: 世界中のプロが本気でやって**年5〜7%**。

だから「**元本保証で月利3%（＝年利36%超）**」という話が来たら、それはプロの数倍の成績を、リスクゼロで、なぜか無名のあなたに配ってくれる、という主張になる。**成立しない**。

### ポンジ・スキーム

1920年代のチャールズ・ポンジに由来する古典的詐欺。運用などしていない。**新しい出資者から集めた金を、古い出資者への「配当」として払う**だけ。最初のうちは本当に配当が出るので、信じた人が家族や友人を連れてくる。新規が途絶えた瞬間に破綻する。**構造上、必ず破綻する**。

### 危険信号（1つでも当てはまったら関わらない）

- **元本保証**＋**高利回り**の同時主張（最重要。リスクとリターンは必ず比例する）
- 「月利◯%」「年利20%以上」を**確実に**と言う
- **紹介すると報酬**（MLM構造）。友人・先輩・SNSの知人から来る
- 運用の中身を説明できない／「AIが自動で」「海外の特別なルート」と抽象的
- **金融庁の登録がない**
- 「今だけ」「あなただけ」「秘密にして」と急かす・口止めする
- 出金しようとすると手数料や条件をつけて渋る

**確認方法**: 金融庁サイトの「免許・許可・登録等を受けている業者一覧」と「無登録で金融商品取引業を行う者の名称等について」（警告リスト）で名前を検索する。30秒でできる。

> 若手社会人は**狙われる側**。「同級生から久しぶりに連絡が来て、カフェで先輩を紹介される」は典型パターン。断れないなら「親／詳しい人に相談してから」で持ち帰る。**まともな金融商品は、持ち帰って冷静に検討されても困らない**。

### 導入クイズの答え合わせ

- 1は元本保証＋高利回り＋紹介報酬で**3アウト**
- 2は年利30%＋中身が説明できない。スクショは何の証明にもならない
- 3は**まとも**。「元本保証なし」と正直に言っているのが逆に健全
- 4は相場の2倍の利回りを毎月配る＝**元本を削って配っている**可能性が高い

## 3. 複利 — この回でいちばん大事な概念

### 単利と複利

- **単利**: 元本にだけ利息がつく
- **複利**: 利息にも利息がつく。増えた分が次の利息を生むので、**時間が経つほど加速する**

### 72の法則

```
資産が2倍になる年数 ≒ 72 ÷ 年利(%)
```

- 年利6% → 約12年で2倍
- 年利3% → 約24年で2倍
- 年利0.001%（かつての普通預金）→ 約72,000年で2倍

**この式は逆向きにも使える**。「年利36%」を謳う話は「2年で倍」と言っているのと同じ。**その時点で怪しいと気づける**。

### 積立の威力（年利5%と仮定した場合の概算）

| 毎月の積立 | 期間 | 元本      | 最終額（概算） |
| ---------- | ---- | --------- | -------------- |
| 3万円      | 10年 | 360万円   | 約466万円      |
| 3万円      | 20年 | 720万円   | 約1,233万円    |
| 3万円      | 30年 | 1,080万円 | 約2,500万円    |

30年では、元本1,080万円に対して**増えた分が1,400万円超**。増えた分のほうが元本より大きくなる。**複利の効果を最大化する変数は利率ではなく「時間」**で、20代で始められることが最大の武器になる。

※ これは「毎年きっちり5%増える」場合の計算。実際の相場は上下しながら平均的にこうなるだけで、**保証ではない**。

## 4. 投資とNISA — 何をどう買うのが「普通」なのか

### 投資の前にやること（順番が大事）

1. **生活防衛資金**を貯める（生活費の3〜6か月分を現金で）
2. **高金利の借金を返す**（リボ・カードローンは年15%前後。どんな投資より確実に「年15%の損失」を止められる）
3. 余った金で投資する

順番を守らないと、暴落時に生活費が必要になって最悪のタイミングで売る羽目になる。

### 初心者の「普通」は1行

**低コストのインデックスファンドを、毎月定額で、長期間積み立てる**。

- **インデックスファンド**: 何百〜何千社にまとめて投資する詰め合わせ。全世界株式（オルカン）やS&P500が定番。1社が潰れても全体は死なない
- **低コスト**: 保有中ずっと引かれる手数料（信託報酬）が年0.1%か年1.5%かで、30年後には数百万円の差になる。**手数料は唯一、確実にコントロールできる要素**
- **毎月定額**: 高いときは少なく・安いときは多く買える。買うタイミングを当てにいかなくて済む

個別株・FX・暗号資産・不動産は初手では扱わない。

### NISAとは

通常、投資で得た利益には**約20%の税金**がかかる。100万円儲けたら約20万円取られる。**NISA = この税金がゼロになる口座**。

- **iDeCo**は掛金が所得控除になる代わりに**60歳まで引き出せない**。若いうちはNISA優先が一般的なセオリー

**枠の数字（2024年〜の制度）**。上限はあるが、20代の積立額なら気にしなくていい。

| 項目                   | 内容                                           |
| ---------------------- | ---------------------------------------------- |
| つみたて投資枠         | 年120万円まで。長期積立に適した投資信託に限定  |
| 成長投資枠             | 年240万円まで。個別株なども対象                |
| 年間合計               | **360万円**                                    |
| 生涯の非課税保有限度額 | **1,800万円**（うち成長投資枠は1,200万円まで） |
| 非課税期間             | **無期限**                                     |
| 売ったとき             | 翌年、その分の枠が復活して再利用できる         |

- 口座は**1人1口座**（金融機関は年単位で変更可）。ネット証券で開くのが定番
- 利益にかかる税率は正確には20.315%

> ⚠️ NISAは「口座の種類」であって、儲かる商品ではない。**NISAでも元本割れはする**。

## 5. 保険 — 入るべきもの、たぶん要らないもの

### 大原則

保険は「**起きる確率は低いが、起きたら貯金では払えない損害**」に備えるもの。

- 貯金で払える金額 → **保険にしない**（手数料の分だけ損）
- 払えない金額（数千万〜億） → **保険にする**

**払う保険料の合計は、平均すればもらう保険金より多くなる**（保険会社の経費と利益が乗っているため）。それでも入るのは、「めったに起きないが起きたら破産する損失」を毎月の少額で肩代わりしてもらうため。保険は儲ける仕組みではなく、**破産を避けるための固定費**。

### 民間保険の前に「公的保険」を知る

すでに加入している健康保険・年金がかなり手厚い。

- **高額療養費制度**: 医療費の自己負担には月あたりの上限がある。平均的な年収なら**月10万円弱程度**で頭打ち。「がんになったら1,000万円かかる」は、この制度を無視した営業トーク
- **傷病手当金**: 会社員が病気で働けない間、給与の約2/3が最長1年6か月出る
- **遺族年金・障害年金・労災**: 死亡時・障害時・業務中のケガに備えは既にある

### 入る／入らないの目安

| 入る価値が高い                                   | たぶん要らない                                                       |
| ------------------------------------------------ | -------------------------------------------------------------------- |
| **火災保険**（賃貸でも。全焼＝数千万円）         | 医療保険・がん保険（高額療養費制度があるので貯金で足りる）           |
| **自動車保険の対人・対物無制限**（賠償は億単位） | **貯蓄型保険**（終身・学資・外貨建て。手数料が見えにくく途中解約で元本割れ） |
| 掛け捨ての死亡保険（**扶養家族がいる場合のみ**） | スマホ保険・延長保証（損害が小さい＝貯金で払える）                   |
| 自転車保険（自治体によっては義務）               |                                                                      |

**ポイントは「不要と断定すること」ではなく、判断基準を持つこと**: ①その損害は貯金で払えるか ②公的保険でどこまでカバーされるか ③手数料はいくらか。この3つを聞いて答えられない勧誘からは買わない。

## 6. 確定申告 — 自分で税金を計算して申告する

### 会社員とフリーランスで何が違うのか

所得税は「1年間の所得が確定してから正しい額を計算する」税金。誰がその計算をやるかが違う。

| 項目               | 会社員                                                   | フリーランス                                                     |
| ------------------ | -------------------------------------------------------- | ---------------------------------------------------------------- |
| 所得税の払い方     | 毎月の給与から概算で**天引き**（源泉徴収）               | 天引きしてくれる会社がない。**自分で計算して納付**               |
| 1年の精算          | **年末調整**。会社に控除の書類を出せば会社がやってくれる | **確定申告**。1年分の収入と経費を自分で集計して申告する          |
| 住民税             | 翌年6月から給与天引き                                    | 納付書が届くので自分で払う                                       |
| 健康保険・年金     | 健康保険・厚生年金。会社が半分負担し、給与天引き         | 国民健康保険・国民年金。**全額自己負担**で自分で払う             |
| 経費               | 給与所得控除として自動で引かれる（申告不要）             | 実際に使った経費を**自分で記録して**引く（レシート・帳簿が必要） |
| やることの量       | ほぼゼロ。書類を1回出すだけ                              | 日々の記帳＋年1回の申告                                          |

- **確定申告**は毎年**2月16日〜3月15日**ごろ（対象は前年1〜12月）。国税庁の「確定申告書等作成コーナー」からスマホ＋マイナンバーカードで送信できる
- **会社員で副業している人は両方**。給与分は年末調整、副業分は確定申告、の二段構えになる

> フリーランスの「手取り」は、税金・国保・年金を自分で払った後の額。**売上＝手取りではない**。売上の3割程度は翌年の税金・保険料として別口座に取り分けておく、が定番の自衛策。

### 確定申告が「必要」な人（デザイナー・エンジニアに多いケース）

- フリーランス・業務委託で働いている
- 会社員だが**副業の所得が年20万円を超える**（案件・広告収入・物販など）
- 給与を2か所以上からもらっている

### 白色申告と青色申告

フリーランス・副業で事業をやるなら、申告のやり方に2種類ある。

| 項目           | 白色申告                         | 青色申告                                                          |
| -------------- | -------------------------------- | ----------------------------------------------------------------- |
| 事前手続き     | 不要                             | **開業届＋青色申告承認申請書**を税務署に出す（開業から2か月以内） |
| 帳簿           | 簡易な記帳                       | 複式簿記（会計ソフトを使えば自動でできる）                        |
| 特別控除       | なし                             | **最大65万円**を所得から引ける（e-Tax提出が条件）                 |
| 赤字の繰越     | できない                         | **3年間繰り越せる**（翌年以降の黒字と相殺）                       |
| 30万円未満の物 | 数年に分けて経費（減価償却）     | **買った年に一括で経費**にできる（PC・カメラなど）                |

**結論**: 事業としてやるなら青色一択。差は「書類を2枚出すかどうか」と「会計ソフトを使うかどうか」だけで、控除の差は年数万〜十数万円の税額になる。**申請書を出し忘れた年は白色扱い**になるので、開業を決めたらすぐ出す。

### 知らないと損するポイント

- **副業所得20万円以下でも住民税の申告は必要**。「20万円以下なら何もしなくていい」は誤り
- **業務委託の報酬は10.21%が源泉徴収されている**ことが多い（支払調書・請求書で確認）。所得が少ないうちは**確定申告すると払いすぎた分が戻ってくる**。申告しないと戻らない
- **経費にできるものを知る**: PC・ソフト・フォント・書籍・セミナー・通信費や家賃の事業使用分（按分）。**レシート・請求書を捨てないことがすべて**。会計ソフトならスマホで撮って保存できる
- **還付申告は5年さかのぼれる**。「去年やり忘れた」は取り返せる
- **期限を過ぎると無申告加算税・延滞税が上乗せ**される。間に合わなくても放置せず出す
- **会社に副業を知られたくない場合**: 確定申告書で住民税を「自分で納付（普通徴収）」にチェックする。給与天引きにすると会社に住民税額が通知される
- 会社員でも得するケース: 医療費が年10万円超（医療費控除）、年の途中で退職して年末調整を受けていない、ふるさと納税でワンストップ特例を使わなかった

### ツール

| ツール                                | 用途                                                                                                                                                                                  |
| ------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **国税庁 確定申告書等作成コーナー**   | 無料。会社員の医療費控除・ふるさと納税程度ならこれで十分                                                                                                                              |
| **freee会計**                         | 事業用のクラウド会計。銀行・カードを連携して仕訳を自動化、青色申告の書類まで出せる。簿記を知らなくても質問形式で進める                                                                |
| **マネーフォワード クラウド確定申告** | freeeと同系統。簿記の形式に近いUIなので、簿記を知っている人や税理士と共有する人に向く                                                                                                 |
| **マネーフォワード ME**               | **家計簿アプリ**（事業用ではない）。銀行・カード・証券・電子マネーを連携すると、何にいくら使ったかが自動で見える。**まず自分の固定費と手取りの行き先を把握する**ために、学生のうちから入れておく価値がある |

> どのツールでも中身は同じ「収入 − 経費 − 控除」。ツールを覚えることより、**日々の入出金が全部どこかに記録されている状態**を作ることが本体。家計はマネフォME、事業は会計ソフト、と分けるのが定番。

## 7. ふるさと納税 — 税金の前払いで返礼品をもらう

### しくみ

「納税」という名前だが実態は**自治体への寄附**。寄附額のうち2,000円を超える部分が、翌年の住民税・所得税から差し引かれる。

**つまり**: 実質2,000円の自己負担で返礼品（寄附額の3割相当まで）がもらえる。**節約ではなく「払う場所を変えるだけ」**という理解が正しい。

### 絶対に外せない注意点

- **上限額がある**。年収・家族構成で決まる控除上限を超えた分は、ただの寄附になる（戻ってこない）。各サイトのシミュレーターで必ず試算する
  - 目安表: [ふるさと納税 控除上限額の目安（鹿児島市・PDF）](https://www.city.kagoshima.lg.jp/soumu/zeimu/shiminzei/shise/yosan/oensite/documents/koujyomeyasu.pdf)
- **そもそも税金を払っていない人は損しかしない**。学生・無収入・住民税非課税の人がやると、2,000円払って返礼品を買っただけになる。**社会人になって、住民税を払うようになってから始める**
- **名義は本人**。自分が納税者でないといけない
- **ワンストップ特例**: 確定申告しない会社員で、寄附先が5自治体以内なら、申請書を出すだけで確定申告不要。**申請期限は翌年1月10日必着**。ただし確定申告をすると**ワンストップは無効になる**ので、その場合は寄附金控除も確定申告に含める
- 仲介サイトのポイント付与は規制された。**サイト選びのうまみは以前より小さい**

### 手順

1. シミュレーターで上限額を確認する
2. ポータルサイト（さとふる／楽天ふるさと納税／ふるなび等）で返礼品を選んで寄附する
3. ワンストップ特例の書類を返送する（または確定申告する）
4. 翌年6月の住民税決定通知書で、控除されているか確認する ← **ここまでやって完了**

## 8. 両学長 / リベラルアーツ大学 — もっと知りたくなったら

### 中心にある考え方「5つの力」

1. **貯める**（支出を減らす） — 固定費（通信費・保険・家賃・車・サブスク）から削る。効果が大きく、一度やれば続く
2. **稼ぐ**（収入を増やす） — 給与所得＋事業所得。**我々はここが強い**（Web制作・デザイン・コーディングは副業にしやすい）
3. **増やす**（投資する） — インデックス投資が基本
4. **守る**（減らさない） — 詐欺・ぼったくり商品・浪費を避ける
5. **使う**（満足度を上げる） — 貯めるのが目的ではない
