## この回でやること

ターミナルの基本操作を覚えて、マウスを使わずにフォルダ・ファイルを扱えるようになる。

## 準備: 使うターミナル

### Mac: cmux

標準の「ターミナル.app」ではなく [cmux](https://cmux.com/) を使う（軽量で複数タブ/ペインの管理がしやすいターミナル）。

- ダウンロード: [公式サイト](https://cmux.com/)から .dmg をダウンロード → cmux をアプリケーションフォルダにドラッグ
- 初回起動で「開発元を確認したアプリを開きますか」と聞かれたら「開く」でOK
- 参考: [公式Getting Started](https://cmux.com/docs/getting-started) / [GitHub（README日本語版）](https://github.com/manaflow-ai/cmux/blob/main/README.ja.md)

### Windows: Git Bash

- Git for Windowsに付属する「**Git Bash**」を使う。下の8コマンドがMacと同じように全部使える
- PowerShellやコマンドプロンプトは一部コマンドが使えないので、授業では**Git Bashに統一**
- VS Codeのターミナルも既定シェルをGit Bashにできる: ターミナルパネルの「+」横の「▼」→「既定のプロファイルの選択」→ Git Bash

## 基本コマンド

| コマンド | 由来 | 何をする | 使用例 |
| --- | --- | --- | --- |
| `cd` | change directory | フォルダを移動する | `cd Documents`（中へ）、`cd ..`（1つ上へ）、`cd ~`（ホームへ） |
| `ls` | list | 今いるフォルダの中身を一覧表示 | `ls`、`ls -la`（隠しファイル・詳細も表示） |
| `pwd` | print working directory | 今いる場所（パス）を表示 | 迷子になったらまず `pwd` |
| `mkdir` | make directory | フォルダを作る | `mkdir my-site` |
| `touch` | — | 空のファイルを作る | `touch index.html` |
| `rm` | remove | ファイルを削除する | `rm memo.txt`、フォルダごとは `rm -r old-folder` |
| `cp` | copy | ファイルをコピーする | `cp index.html backup.html`、フォルダごとは `cp -r` |
| `mv` | move | ファイルの移動 or 名前の変更 | `mv style.css css/`（移動）、`mv old.txt new.txt`（改名） |

⚠️ `rm` は**ゴミ箱を経由せず即座に消える**。特に `rm -r` は取り返しがつかないので、打つ前に `pwd` と `ls` で場所と対象を確認する癖をつける。

## やってみる

コマンドだけで「作業用フォルダを作る → 中に `index.html` を作る → 名前を変える → 削除する」を一通りやってみる。
